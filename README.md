# ⚡ Talent UI Hub

**Talent UI Hub** is a state-of-the-art Next.js 16 & React 19 showcase featuring **10 fully interactive custom dashboards**, animated CSS/SVG loaders, and a comprehensive reusable UI component gallery built with Tailwind CSS v4, Framer Motion, and Recharts.

---

## ✨ Features

- 🎨 **10 Live Interactive Dashboards**:
  - **eProduct**: E-Commerce & Order Management Dashboard
  - **SkillSet**: EdTech & Learning Analytics Platform
  - **Finnova**: Financial Technology & Portfolio Tracker
  - **Horizon**: SaaS Analytics & Subscription Management
  - **MedPulse**: Healthcare & Patient Care Portal
  - **TaskFlow**: Agile Project & Task Management Board
  - **StyleHaven**: Luxury Fashion & Retail Analytics
  - **DevPulse**: Developer Performance & CI/CD Monitor
  - **CryptoVault**: Web3 & Cryptocurrency Asset Manager
  - **Analytics Pro**: Universal Business Intelligence Suite

- 🌀 **Animated Loaders Gallery**:
  - CSS & SVG spinner variations, glowing rings, pulse effects, and skeleton loaders.

- 🧩 **UI Component Gallery**:
  - Interactive cards, modal dialogs, status badges, customized buttons, tab navigation, and chart widgets.

- 💎 **Modern Aesthetics**:
  - Dark-mode optimized, glassmorphism card surfaces, vivid color gradients, responsive layout grid, and micro-interactions.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **UI Core**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts**: [Recharts](https://recharts.org/)
- **Language**: TypeScript

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js 18+** and `npm` installed.

### Installation

1. Clone or navigate into the project directory:
   ```bash
   cd talent-ui-hub
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to explore the showcase.
